# Phase 6: Social & Community Features

**Status**:  **COMPLETE**
**Date**: December 11, 2025
**Expected Start**: Started Q4 2025

---

##  Goal

Turn Freestyla from a solitary practice tool into a vibrant community where rappers can share, compete, and grow together.

##  Key Features

### 1. Public Profiles & Feeds

- [ ] **User Profile V2**: Showcase "Best Bars", streaks, and badges.
- [ ] **Activity Feed**: See when friends record a new session or earn a badge.
- [ ] **"Fire" & Comments**: Social validation for public recordings.

### 2. The "Duel" System

- [ ] **Challenge Mode**: Send a specific Beat + Word Seed combination to a friend.
- [ ] **Split Screen Playback**: Compare two takes on the same beat side-by-side.
- [ ] **Voting**: Community voting on who won the duel.

### 3. Discovery

- [ ] **"Trending" Page**: Top recordings of the week.
- [ ] **Leaderboards**: Ranked by "Flow Density", Streak, or Community Votes.
- [ ] **Hashtags**: Organize sessions by style or challenge (e.g., #SpeedChallenge).

### 4. Audio & Sharing Polish

- [ ] **Audio Watermark**: Append "Recorded on Freestyla" audio tag to the end of downloaded files (Brand Growth).
- [ ] **Social Sharing**: Link preview generation (OGP tags) for `flowforge.com/r/[id]`.

---

##  High-Level Roadmap

- **Week 1-2**: Database schema for Social Graph (Follows, Likes, Comments).
- **Week 3-4**: Public Profile UI and Feed implementation.
- **Week 5-6**: Sharing mechanics (Link preview generation, OGP tags) and Audio Watermarking.
- **Week 7-8**: "Duel" logic and notifications.

---

##  Vision

Social features are the "viral engine" of Freestyla. While the tool provides utility, the community provides retention.
